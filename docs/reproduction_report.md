# Independent reproduction record

## Who and how

- **Reproducer.** A separate automated agent (Claude) that had not written or run any of the
  code. It was given only the repository URL and branch, the README procedure and the two price
  snapshots; it had no access to the implementation session. This is independent of the
  implementation but is not a human reproduction; a co-author who did not implement the system
  should repeat it before publication (procedure below).
- **Environment.** Fresh clone of branch `paper-fixes` at 857d7e5; CPython 3.13.16, pandas
  2.2.3, numpy 2.2.6, pyarrow 26; 2 CPU cores; offline, with a socket guard that logged and
  refused every outbound connection (its log stayed empty). No paid model calls.
- **Inputs.** `release/confirmatory_llm_cache.tar.gz` (SHA-256 `a431e59f...c93cd`; Sonnet 5.5
  22,133, Haiku 5.5 48,170, DatedGPT 3,918 + 471 responses), the input-data folders, and the
  price snapshots, all checked against the hashes in `docs/run_manifest.json`.

## What was checked and the outcome

| Check | Outcome |
|---|---|
| Results without fresh paid calls | all 119 cells ran from the released responses; 0 cache misses, 0 failed calls |
| Run identifiers -> tables | cell set identical to `results/raw`; per-cell excess returns, weights, equity and turnover max abs diff 0.0; `llm_stats` identical (unparseable counts included) |
| Model, prompt, configuration and data versions | model keys and per-run response counts, system-prompt hashes, price and input hashes equal to the manifest |
| Execution and accounting | equity, gross/net returns and turnover identical; engine unit tests pass |
| Tables | 23 of 25 result tables byte-identical; every number the paper uses identical once the two causes below were fixed |
| External-code audit references | every commit, file and cited line in `docs/public_code_audit.md` re-read at the recorded commit (blobless clones, 5 Nov 2026): all present and as described |

A second check from another fresh clone, with only the release files and network disabled,
reproduced four cells (no-LLM pipeline, Haiku debate, DatedGPT placebo, DatedGPT 2016-2021
pipeline) with identical values.

## Discrepancies and resolution

| # | Discrepancy | Cause | Resolution |
|---|---|---|---|
| 1 | `clean_diag.json` values differed | the diagnostic read every DatedGPT response, including the 2016-2021 ones added later | restricted to 2022-2024; reproduces the committed values (0f7ed67) |
| 2 | `mechanisms_clean.json` key differences | committed file was written by an older script | regenerated with current code (0f7ed67) |
| 3 | 12 `numbers.tex` keys (`loo.*`, `hfour.*`) pending in the reproduction | exploratory leave-one-out attribution from pre-freeze responses that are not released; not used in the paper | documented in README and the script; slots print `\pending` |
| 4 | 27 `numbers_v2.tex` keys | reference file written by code committed two minutes later (240fe18); `chk.npass` counted C2 parts separately at 857d7e5 | reproducing at 240fe18 is byte-identical; README now requires the branch head |
| 5 | Implementation audit (Table 7) not regenerated by the script; archived crypto-weekend row stale (Sharpe 0.33 vs 0.15 with current code) | audit predated later engine fixes | rerun with current code, added to the script, paper updated (0f7ed67) |
| 6 | Input-data folders not in the repository | gitignored | released as `release/input_data_snapshot.tar.gz`, hashed per folder (0f7ed67) |
| 7 | Failing cells would go unnoticed (`set -e` cannot see them) | runner exits 0 when a cell fails | `verify_reproduction.py` compares a rebuilt manifest with the reference and exits non-zero |
| 8 | File hashes differ under pandas 3 although values are identical | parquet metadata depends on library version | manifest records a value hash; the verifier uses it (d22bf6c) |
| 9 | Manifest rebuild overwrote a tracked file; README/script header stale | — | `build_manifest --out`; header, Python versions, runtime and tarball contents documented |

## Procedure for a human reproduction

```bash
git clone -b paper-fixes <repository> && cd PACT && pip install -e .
PX_B=<2022-2024 snapshot> PX_C=<2016-2021 snapshot> SKIP_SLOW=1 bash scripts/reproduce_paper.sh
```

The last step prints `119/119 reference cells present; 0 problems`; `results/paper_tex/` then
holds every number and table in the paper. About 7 CPU-hours on 2 cores.
