# Automated reproduction record

## Who and how

- **Reproducer.** A separate automated agent (Claude) that had not written or run any of the
  code. It was given only the repository URL and branch, the README procedure and the two price
  snapshots; it had no access to the implementation session. It is separate from the
  implementation session but is not a human reproduction; a co-author who did not implement the system
  should repeat it before publication (procedure below). It is a reproduction check (do the
  released code and responses regenerate the reported numbers?), not an independent
  reimplementation, and it does not establish that the implementation is correct.
- **Clean environment; write access.** It was instructed to work only in its own fresh clone and
  environment and not to change implementation code (it ran in the same container as the
  repository, so this was an instruction, not an access control). The fixes listed under "Discrepancies" were made by the
  implementer in the repository (commits given), not by the reproducer.
- **What was compared.** Per-cell excess returns, weights, equity, turnover and `llm_stats`
  against `results/raw`; every value in `numbers.tex` and `numbers_v2.tex`; the 25 result
  tables; model keys, response counts, prompt, price and input hashes against
  `docs/run_manifest.json`; and every reference in `docs/public_code_audit.md`.
- **Environment.** Fresh clone of branch `paper-fixes` at 857d7e5; CPython 3.13.16, pandas
  2.2.3, numpy 2.2.6, pyarrow 26; 2 CPU cores; offline, with a socket guard that logged and
  refused every outbound connection (its log stayed empty). No paid model calls.
- **Inputs.** `release/confirmatory_llm_cache.tar.gz` (SHA-256 `a431e59f...c93cd`; Sonnet 5.5
  22,133, Haiku 5.5 48,170, DatedGPT 3,918 + 471 responses), the input-data folders, and the
  price snapshots, all checked against the hashes in `docs/run_manifest.json`.

reproduced four cells (no-LLM pipeline, Haiku debate, DatedGPT placebo, DatedGPT 2016-2021
pipeline) with identical values.

## Procedure for a human reproduction

```bash
git clone -b paper-fixes <repository> && cd PACT && pip install -e .
PX_B=<2022-2024 snapshot> PX_C=<2016-2021 snapshot> SKIP_SLOW=1 bash scripts/reproduce_paper.sh
```

The last step prints `119/119 reference cells present; 0 problems`; `results/paper_tex/` then
holds every number and table in the paper. About 7 CPU-hours on 2 cores.

## Addendum: controlled experiment (added after the reproduction above)

The four DatedGPT cells of the controlled 2x2 (`b__clean__ctrl_*`, pre-registration v3) and the
calibration study were run after this reproduction, at commit f595b6c. They are checked by an
offline replay from the released responses (`scripts.analyze_controlled`: 0 cache misses, max
abs difference from the saved excess returns 0.0 in all four cells; A/B and C/D revised views
identical). A second automated agent, given only the fresh clone at b39c519, the release
files and the 2022-2024 price snapshot (torch not installed, network blocked), reran the four
cells and `analyze_controlled`: excess returns and weights max abs diff 0.0, `llm_stats`
identical, 0 failed or unparseable calls, all 128 values of `controlled_clean.json` identical;
input and response-count hashes matched the manifest. Differences: commit hash in metadata
(cells ran at f595b6c; later commits change only analysis scripts) and parquet bytes under
pandas 3.0.5 (values identical). The verifier cannot be restricted to a subset of cells, so a
partial rerun reports the other 119 as missing. The second agent was given the same instruction and made no code changes (`git status` of its clone is clean). The calibration simulation was not rerun. Outputs regenerated by the implementer after the first check (fixes 1, 2 and 5) were not re-checked by a reproducer; the second rerun used the current code but covered only the controlled cells. Price snapshots are not redistributed (Yahoo terms); they are identified by per-file hashes in `docs/run_manifest.json`, so an outside reproducer needs the same snapshots. The release cache now includes their 1,727 `scorer-v2-fp32` responses
(SHA-256 `7a5dd700...708c3d8f`), and `docs/run_manifest.json` lists 123 cells.
